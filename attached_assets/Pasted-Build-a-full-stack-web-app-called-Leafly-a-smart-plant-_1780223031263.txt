Admin username: admin | password: leafly2024 (hardcoded for now, changeable later).

The admin must be able to do ALL of the following without touching code:

PLANT MANAGEMENT

View all plants in a table: name, price, size, category, status (available/unavailable)
Edit any plant's: name, price, size, category, care difficulty, description, climate tags
Toggle a plant on/off (show/hide from customer shop)
Delete a plant
Add a new plant with all fields
IMAGE UPLOAD

Each plant has an "Upload Image" button in the admin panel
Admin can upload a JPG/PNG image from their computer
Image is stored on the server (use multer for file uploads in Node.js)
Uploaded image replaces the placeholder on the plant card in the shop
Show a preview of the uploaded image in admin before saving
PRICE EDITOR

A dedicated "Price Manager" tab in admin
Shows all plants in a simple editable list: plant name | current price | edit field | save button
Admin can change any price and click Save — updates instantly in the shop
Paan Patta is listed here with price = 0 and status = Unavailable, ready to be activated
ADENIUM COLOR VARIANTS

Admin can add color variants for Adenium (e.g. Red, Yellow, White, Purple)
Each variant has its own price
Pink is pre-seeded at Rs. 650
ORDER MANAGEMENT

View all orders: order ID, customer name, city, items, total, status
Update order status: Confirmed / Packed / Out for Delivery / Delivered
Filter orders by city and status
HIRE-A-PRO BOOKINGS

View all service bookings: name, phone, city, service type, date, notes
Mark as confirmed / completed / cancelled
